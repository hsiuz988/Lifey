# Lifey · 人生紀錄

🔗 **網址：https://app.lifey.workers.dev**

只給自己用的手機網頁 App（PWA），靈感來自《80 億分之 1》：把真實人生中值得記住的時刻，依「幾歲」排成時間軸，長期累積、隨時回顧。

## 目前功能

- 第一次開啟設定名字與生日，頂部顯示目前幾歲、這一歲過了多少
- 「＋ 記一筆」：日期（可改到過去補回憶）、一句話、照片（最多 4 張）、心情、標籤、☆ 值得記住
- **人生地圖**：一格一年共 90 格，顏色是那一年的平均心情，有 ☆ 的年份會發光；點格子可寫「這一歲的一句話」或在那一歲記一筆
- **回憶模式**：從 0 歲開始一歲一歲補填，依台灣學制推算「大約是國小二年級」並給對應的提示問題；不確定日期也能記（時間軸顯示「這一年」），翻頁或關閉自動儲存，下次從中斷處繼續
- 時間軸依年歲分組；點 ☆ 直接標記，點文字編輯／刪除，點照片看大圖（可左右滑）
- **今年的狀態**：健康、幸福、知識、人際關係（0–100），由這一歲記下的事件與心情累積，不用自己打分數；可選「今年的重心」
- **捏自己的小人**：性別（只影響體型與學生制服）、膚色、7 種髮型、髮色、眼睛、睫毛、腮紅、雀斑、鬍子、5 種衣服與顏色、眼鏡／帽子／耳機／髮夾，全部自由搭配；可預覽不同年紀，會從嬰兒長到老年（白髮、拐杖），學生時期自動穿制服
- **會動的場景**：天空隨真實時間平滑變化（日出、正午、黃昏、星空、月相），雲飄、鳥飛、樹葉晃，小人會呼吸、眨眼、散步；點小人會說話；記一筆會開心跳、☆ 會放小煙火
- **真實天氣**（選用）：開啟定位後依 Open-Meteo 的天氣下雨、起霧、轉陰，日出日落也更準；位置只存約略值在手機上
- **四季與節日**：春天花瓣、秋天落葉、夏夜螢火蟲；生日氣球蛋糕、過年燈籠、中秋滿月、聖誕燈、跨年小煙火
- **省電與舒適**：約每秒 10 格，切到背景或捲出畫面就暫停；系統開啟「減少動態效果」時只顯示靜態畫面
- **人生大事**：60 個快捷鍵（學業、工作、感情、家庭、生活、旅程、健康、人生第一次、告別），點一下帶入文字、標籤與 ☆，需要時接著問「和誰」；出現在時間軸與人生地圖；告別類不慶祝、語氣溫和
- **人物**：家人、朋友、寵物；記一筆時點選「和誰」，人物卡可看一起的回憶、從人物篩選時間軸；寵物（狗、貓、兔、鳥、倉鼠、魚 × 4 色）會在場景裡跟著小人走，去了彩虹橋後就不再出現
- **成就**：17 個徽章，預設隱藏（背後照樣記錄），可在設定打開
- 篩選（全部／☆／有照片／標籤）與搜尋
- 身分紀錄卡（含護照式 MRZ 裝飾）
- **心情與花園**：記錄時分成事件和心情，自動判斷 10 種情緒（也能自己選）；小人的表情、動作跟著今天的情緒，今天記的事（咖啡、跑步…40 種小圖）會出現在場景裡；一天一朵花，點右下角的小花圃打開「心情花園」，花的種類是情緒、顏色是心情好壞
- **AI 故事**（選用，需登入雲端）：把事件和心情改寫成「那一年的世界」語氣的一小段故事，順便判斷情緒和小圖
- **雲端同步**：用 Face ID（Passkey）登入，文字與照片同步到自己的 Cloudflare（D1＋R2）；兩台手機同時改也會逐筆合併，刪除會同步
- **另一半**：用邀請連結建立帳號並自動連結；只會看到對方標成「💞 分享」的紀錄與照片，可對照「我們在同一個年紀」
- 匯出／匯入 ZIP 備份（含照片，可整個取代或合併），也能匯入階段 1 的 JSON 備份
- 可加入主畫面、離線使用

**資料（含照片）只存在手機瀏覽器的 IndexedDB**，不會上傳。換手機或清除網站資料前一定要先匯出備份。

## 照片怎麼處理

- 選照片後在手機上直接重新編碼成 JPEG：原圖長邊 2048px（約 300–600KB），另存 480px 縮圖給時間軸用
- 依 EXIF 方向自動轉正，並移除 EXIF（包含 GPS 位置）
- iPhone 選相簿時會自動把 HEIC 轉成 JPEG
- 先存照片、再存文字；中途失敗留下的孤兒照片，下次開啟時自動清掉

## 備份檔格式

```
lifey-YYYY-MM-DD.zip
├── data.json              # 所有文字資料（version 2）
└── photos/
    ├── <id>.jpg           # 原圖
    └── <id>-thumb.jpg     # 縮圖（缺少時匯入會自動重建）
```

## 本機試用

```bash
npm install
npx wrangler dev
# 打開 http://localhost:8787
```

## 架構

```
public/        網站（PWA），離線也能用，資料存在手機的 IndexedDB
worker/        Cloudflare Worker，只處理 /api/*
  auth.js      Face ID／Passkey 登入（@simplewebauthn/server）、session cookie
  data.js      同步（整份文字資料＋樂觀鎖）、照片、邀請與另一半檢視
  schema.js    D1 資料表（第一次請求時自動建立）
```

- 同步：先拿雲端版本，逐筆合併（較新的 `updatedAt` 勝出，刪除留墓碑），再用版本號寫回；兩台同時寫入會重新合併
- 第一個帳號可直接建立，之後只能用邀請連結建立（避免陌生人註冊）
- 另一半只拿得到 `shared` 的紀錄與其照片；另一半的照片不快取，取消分享立刻生效

## 預覽網址

推到 `main` 以外的分支時，Cloudflare 會建一個預覽版本（Workers Builds 的 Preview builds），可以先在手機上試，不影響正式網址。
預覽和正式機共用同一個 D1／R2，在預覽建立的帳號和資料會留在正式資料庫裡。

## 部署（Cloudflare Workers）

每次推到 `main` 會自動重新發布（Workers Builds 會自動 `npm install`，再 `npx wrangler deploy`）。
`wrangler.jsonc` 需要填入 D1 資料庫 ID，照片存在 R2 bucket `lifey-photos`。

本機開發：`npm install && npx wrangler dev`（會用本機模擬的 D1／R2）

## 更新程式後

修改任何檔案後，把 `public/sw.js` 裡的 `CACHE` 版本號 +1（例如 `lifelog-v2`），手機開兩次就會換成新版。

## 規劃

1. ✅ 階段 1：記錄、時間軸、☆、備份
2. 階段 2：✅ 照片、✅ 人生地圖與這一歲的一句話、✅ 回憶模式；人生重播、年度總結卡（之後再做）
3. ✅ 階段 3：四項狀態養成、成就、年度重心、像素頭像與場景
4. ✅ 階段 4：雲端同步（Face ID 登入）、和另一半互看（LINE 提醒暫不做）
